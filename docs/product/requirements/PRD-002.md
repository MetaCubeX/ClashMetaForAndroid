# PRD-002 配置

使用者可以导入配置、在多份配置之间选择当前一份，并保留本地覆盖。导入入口接受 `clash://install-config` 与 `clashmeta://install-config`。

规格见 [配置](../../systems/profiles/INDEX.md)。代码位置见 [追踪](../traceability.md)。
