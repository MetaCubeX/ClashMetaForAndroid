# 隧道

## PRD-001 隧道

状态：已接受。


使用者打开 VPN 后，流量按当前配置进入 mihomo。服务运行在独立于界面的进程中。关闭或重载不要求使用者重装应用。

- PRD-001.1 打开 VPN 后，流量按当前配置进入 mihomo。
- PRD-001.2 隧道服务与界面不在同一进程。
- PRD-001.3 关闭或重载隧道不要求重装应用。

规格见 [运行时](../../systems/runtime/INDEX.md)。代码位置见 [追踪](../traceability.md)。
