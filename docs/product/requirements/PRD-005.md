# WebDAV

## PRD-005 WebDAV

状态：已接受。


使用者可以把配置和分流策略与 WebDAV 目录同步。公共地址必须是 HTTPS。局域网地址可以是 HTTP。未填写密码时不会自动同步。测试连接和拉取不改变远端。推送上传合并结果，不把远端名单写回本机已导入的配置。订阅流量单独同步，配置正文没变时不重传整份配置。

切换账号或远端目录后，不自动上传全部既有本机配置，也不重放旧目标的删除。显式推送将现有配置和策略纳入当前目标；后续成功保存的配置也加入该目标。正在编辑或无法安全应用的配置会提示暂缓，保存或取消编辑后可重试。服务器不能可靠执行条件写入时停止发布，保留待同步内容。

自动同步在改动后稍候再推，未完成的推送继续重试；没有待推送改动时周期任务只拉取。本需求仍为 accepted；跨桌面集成、策略跨进程事务和真机运行验收尚未完成，未承诺完整跨端自动同步。

- PRD-005.1 可以把配置和分流策略与 WebDAV 目录同步。
- PRD-005.2 公共地址必须是 HTTPS；未填写密码时不会自动同步。
- PRD-005.3 测试连接和拉取不改变远端。
- PRD-005.4 推送不把远端名单写回本机已导入的配置。
