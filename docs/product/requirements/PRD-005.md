# PRD-005 WebDAV

使用者可以把配置和分流策略与 WebDAV 目录同步。公共地址必须是 HTTPS。局域网地址可以是 HTTP。未填写密码时不会自动同步。拉取应用到本机。推送上传合并结果，不把远端名单写回本机已导入的配置。

规格见 [WebDAV](../../systems/webdav/INDEX.md)。代码位置见 [追踪](../traceability.md)。
