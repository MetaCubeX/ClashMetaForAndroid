# 分流策略

## PRD-004 分流策略

状态：已接受。


使用者可以保存多份命名的应用名单，并指定哪一份正在生效。编辑某一份策略时，保存的是那一份，不是全局名单。再点已生效的策略保持选中，不取消生效。全局名单只作为未选策略时的默认回退，入口在应用分流页；它的模式和名单也只有一个入口。

- PRD-004.1 可以保存多份命名的应用名单，并指定哪一份正在生效。
- PRD-004.2 再点已生效的策略保持选中，不取消生效。
- PRD-004.3 未选策略时隧道使用全局名单，且该名单只在应用分流的默认回退里编辑。
