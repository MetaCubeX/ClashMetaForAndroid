# PRD-006 外部控制

其他应用可以通过导出的控制入口请求启动、停止或切换隧道。Manifest 里登记的动作使用 meta 包名下的 `START_CLASH`、`STOP_CLASH` 和 `TOGGLE_CLASH`。

没有已导入的当前配置时，启动，以及会因此启动的切换，不启动隧道，并提示没有选择配置文件。已经在运行时再次启动只提示已启动。停止仍停止隧道。这条入口不拉起 VPN 授权。

规格见 [运行时](../../systems/runtime/INDEX.md)。代码位置见 [追踪](../traceability.md)。
