# 界面

`app` 放 Activity 和应用级入口：主界面、配置、代理、设置、日志、访问控制、分流策略、WebDAV、外部控制。

`design` 放屏幕。Activity 创建对应的 `*Design`，再把请求送回 `app`。服务、配置和隧道逻辑仍留在 Activity 与 `service`。

显示名是 ClashMetaX。`applicationId`、`clash://`、`clashmeta://` 和外部控制 action 不变，避免已安装用户和已有自动化失效。launcher 与关于页用 `application_name` / `launch_name`。内核名称仍是 Clash Meta Core。

取舍见 [ADR-002](../../../dev/decisions/002-compose-ios-home.md)。

## 首页层级

首页按使用顺序排。模式、实时上下行和当前节点参考了 [Clash Verge Rev](https://github.com/clash-verge-rev/clash-verge-rev) 的首页卡片。侧边栏、系统代理和 TUN 两套开关、IP 检测、测速和系统信息没有搬过来。Android 只有一条 VPN，连接按钮仍是唯一的隧道开关。

1. 连接状态是唯一主操作。运行中副标题是累计已转发流量；刚连上还没有累计值时显示正在运行。停止且没有配置时，主按钮是「选择配置」，打开配置列表，不尝试启动。已有配置时才是连接。停止不需要确认。
2. 模式是三个等宽按钮，顺序为规则、全局、直连，选中项下面有一行说明。它只写入当前会话的 override。说明下面始终有「仅本次会话有效」，字色比说明更浅。隧道模式是 Script 时三个按钮都不选中，也不显示模式说明，会话提示仍在。代理页不再提供模式菜单。
3. 隧道在跑时出现流量卡。上传用绿色，下载用蓝色，各显示当前速率，下面是最近约 36 秒的折线，以及上传和下载的累计。速率来自 `queryTrafficNow()`，累计来自 `queryTrafficTotal()`。直连模式不显示当前节点。其他模式显示一个策略组里当前选中的节点名，点进去打开代理页。组的选取见 [主界面](../../../app/docs/activities.md)。
4. 「正在使用」放配置、应用分流、代理。核心没在跑时，代理行保留但不可点。有外部资源时才出现提供者。代理行右侧是当前模式的短名。
5. 「工具」放日志和设置。「其他」放帮助和关于。

设置页分成「偏好」（应用、网络）和「高级」（覆写、Meta、WebDAV）。应用页的「界面」第一项是语言。点整行打开选择：第一项是跟随系统，后面按 `locales_config.xml` 的顺序列出已支持的语言，名称用该语言自己的文字。没有保存过、值为空或无法识别时跟随系统，并尊重系统语言以及 Android 13 起的按应用语言。选中后写入 `ui` 偏好的 `app_language`，立刻重建界面。页面标题在重建时按当前语言重新读取。`:background` 启动时读取同一项；进程已在运行时，下一次取文案使用新语言，已经显示的通知保持到下次刷新。每一行下面有一句说明，用来和首页的「应用分流」区分开。点进去仍是分组列表，字段写回原来的属性，不另开一套请求。

## 视觉

新屏幕在 `design/src/main/java/com/github/kr328/clash/design/ios/`。颜色、字号和分组列表按 Apple Human Interface Guidelines 的系统色和 44dp 最小点按来做，亮暗跟随现有 `UiStore.darkMode`。官方 Compose 没有 Cupertino 组件库，所以不引入 Cupertino 依赖。列表行、分组偏好行、51×31 开关和搜索框的源码复制自 AgenticUILibrary（Apache-2.0），放在 `design/src/main/java/nota/ui` 和 `universe/agentic/ui/search`。屏幕只调用 `Ios*` 封装。深色仍由 `ClashMetaXTheme` 按 `UiStore.darkMode` 提供，不读系统夜间模式。

首页、设置顶层和设置子页共用同一套分组行，圆角 10dp，箭头 13dp。连接卡和流量卡也是 10dp。模式按钮保持 12dp。代理、配置、日志、文件和访问控制保持通栏。分组行的说明若把字号收到九成二以上就能排进一行，就排进一行。收不动、末行又只剩一个字时，从上一行多留出约两个字的空。不把整段拆成等长的两行。导航栏高 44dp，背景与页面相同。带导航栏的屏幕把内容裁在导航栏下面，后画的导航栏盖住漏出来的部分，滚动时标题保持完整。设置顶层也用这个脚手架。WebDAV 自动同步的简体、繁体和香港说明是一整句。帮助页和安装包损坏页的网址在每个斜杠后可以换行。网络里的协议栈选项用中文。覆写和 Meta 里不超过一行的短值显示在行尾，放不下或含换行的值留在标题下面。重置按钮是红色。嗅探分组的标题是「嗅探设置」，其中一行是「嗅探策略」。DNS 的策略标题仍是「策略」。

底部弹层的下沿取所在 Activity 根视图上已经应用的系统栏和刘海底边，与 Compose 导航栏底边中较大的那个，再留 8dp。对话框实际画到屏幕外面时，再把超出的高度抬回来。弹层高于剩余高度时可以滚动。遮罩不使用系统窗口变暗：打开时从透明淡到 40% 黑，弹层从屏幕底部滑入；关闭时反过来，250ms 后再执行选中项并收起。动作之间有分隔线。删除配置、删除文件和访问控制菜单下面有取消。覆写重置、Meta 重置和清空日志的确认是破坏性的，红色跟随 `UiStore.darkMode`。未保存退出的确认不是破坏性的。

空列表写「这里是空的」。搜索没有结果写「没有匹配结果」。`empty` 仍表示置空。没有组的代理页仍用原来的空组说明。访问控制在没有关键字且应用表为空时仍用集合空说明。选中是行尾的勾，半选是短横。

代理页导航末端是更多和测速两个图标。测速进行时闪电收起，进度显示在列表上方，不盖住标题。进度留到这次测速自己的重载把延迟画上为止。打开、排序或切换组带回来的结果保持进度。被丢掉的旧结果也不清掉进度。当前节点名放不进行尾时改到标题下面。日志列表没有历史文件时不显示清空。文件日志的导出和删除是图标。实时日志的关闭仍是文字按钮，入口一行是「实时日志」。

关于对话框有确认，只关闭对话框。文本、列表、映射、二维码、拉取进度和策略名称继续 inflate 原来的布局。这些 Material 对话框的卡片是分组背景，圆角 14dp。Snackbar 的背景、文字和动作色按 `UiStore.darkMode` 取分组色、标签色和蓝色。

## 其余屏幕

代理、提供者、配置、新建、属性、文件、日志、访问控制、分流策略，以及应用、网络、覆写、Meta、WebDAV、帮助、安装包损坏和崩溃页，根视图都是 `ComposeView`。规格是 [其余屏幕的分组交互](../../../dev/plans/compose-remaining-screens.md)。关于对话框、订阅二维码、单行文本、列表和映射编辑器、age 密钥对话框、拉取进度仍用原来的布局。页面级 XML 已删除。

和首页同一套约定：44dp 最小点按，按压是背景闪一下，insets 来自 Design 的像素监听，深色读 `UiStore.darkMode`。大标题只在首页。

- 代理页一次只显示一个组。首页当前节点把选中的组名放进非导出的 extra。组名列表为空时不加载第 0 组。只有用户在组列表里点选才写 `proxyLastGroup`。同一组里后返回的旧查询不改变列表顺序，也不改变勾选。查询还在路上就点选时，列表可以更新，勾选留在点中的节点。
- 文件子目录返回根目录时，新建按钮立刻消失，不等列表换回来。根目录不新建。此时若仍收到新建请求，直接返回。目录不显示大小和经过时间。修改时间小于等于 0 的文件也不显示经过时间。有更多操作的文件，更多是行尾图标，菜单标题是文件名，点行仍打开。分流策略页标题是「应用分流」。允许全部时第二行只有模式名。其余模式的已选数量用 `selected_apps_count`，简体写「已选 %d 个应用」，繁体和香港写「已選 %d 個應用」。从某份策略进入名单时，窗口标题是该策略的名称。没有策略 UUID 时，标题是「全局应用名单」。网络设置在已有生效策略时，模式和包列表仍显示各自的值，两行下面另有一句说明当前由该策略接管、这里改的是未选策略时的全局名单。两行的写入目标不变。名单页在应用列表上方显示已选数量。实时日志的级别用翻译后的名称，搜索也能匹配这个名称。搜索框的清除按钮读作「清除」。行尾短值按宽度计算，一个汉字算两个拉丁字母。WebDAV 放得下的地址和账号显示在行尾，长地址留在标题下面。已导入且不是文件的配置，行尾有更新图标，读作「更新」，点它仍走原来的单个更新。更多仍是图标。菜单里不再放更新，标题是配置名，其余动作不变。点行仍设为当前。配置行不显示箭头。已过期的到期日前面写「已过期」，这一行是红色。普通订阅不重复写类型。文件、外部和未保存仍写类型。已用流量在下载小于 2 时不显示。总量大于 1 时写成「已用/总量」，后面带上和用量条相同的百分比，否则只写已用。用量条仍只在总量不少于 2 时出现。有到期日时行上不写更新经过时间。没有到期日时，更新经过时间写在副标题里，不占行尾。
- 实时日志用整表快照，最新一行在顶部，只有垂直滚动停在顶部才跟随。文件日志最旧在顶部，不跟随。
- 访问控制的搜索不替换完整应用表。隐藏系统应用的开关与保存的布尔相反。全选是清空后再写入当前表。
- 配置属性里，age 密钥只显示已设置或未设置。文件类型的来源和间隔显示不可用。
- WebDAV 手动同步、拉取、推送先确认再发送。打开自动同步不确认。同步或测试进行中拨开自动同步，开关和存储都保持关。不忙时从关到开仍立即发同步。

跨模块行为不要只写在某个 `*Design` 类的注释里。访问控制集合的点选规则见 [访问控制](../access-control/INDEX.md)。设置项的存储分别属于 [配置](../profiles/INDEX.md)、[访问控制](../access-control/INDEX.md) 或 [WebDAV](../webdav/INDEX.md)。
