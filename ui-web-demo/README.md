# ClashMetaX (CMFA) UI 2.0 重构方案与交互式 Web 原型

本目录包含 **ClashMetaForAndroid (ClashMetaX)** 界面全新设计的交互式 Web Demo。

## 1. 快速启动与体验方式

本 Demo 零外部依赖，使用纯原生 HTML5 / CSS3 / ES6 构建，支持任意现代浏览器：

### 方式一：本地 Python 预览服务（推荐）
```bash
python3 ui-web-demo/serve.py 8080
# 或自定义端口
python3 ui-web-demo/serve.py 8888
```
浏览器访问：`http://localhost:8080`

### 方式二：直接双击打开
直接使用 Chrome、Edge、Safari 或任何手机浏览器打开 `ui-web-demo/index.html`。

## 2. UI 重构设计思路与核心演进

### 2.1 痛点剖析与现状对比
* **原版旧 UI**：Material 列表进出层级深，切节点需要先点进代理列表并在复杂的分组中翻找，状态感知仅为几个静态数字，缺少出站感知与现代美学。
* **初版 Compose 探索**：虽引入了 iOS 分组卡片风格，但仍偏向“设置表驱动”模式，首页没有充分发挥出移动端网络中枢的“实时仪表盘”价值。

### 2.2 UI 2.0 核心设计支柱
1. **网络状态感知优先 (Perception-First Dashboard)**：
   - 呼吸态大圆环启停按键（断开 / 连接中波纹 / 运行中翡翠发光）。
   - 实时流体 Canvas 流量曲线（60fps 动态正弦噪声波，上传绿、下载蓝，实时吞吐跳动）。
   - 出站节点与 IP 感知卡片：当前出站节点、国家旗帜、出口 IP、数据中心归属及实时延迟色阶。
2. **零路径极速操作链路 (Zero-Latency Switching)**：
   - 首页点击出口卡片直接呼出 **底部极速切节点抽屉 (Quick Node Switcher)**，无需跳转二级页。
   - 模式切换采用胶囊分段器（规则 Rule / 全局 Global / 直连 Direct），触控即生效。
3. **现代移动端 5 大核心 Tab 导航**：
   - **⚡ 仪表盘 (Dashboard)**：状态主控、出站感知、实时速率折线、订阅余量与分流快捷微组件。
   - **🌐 节点选择 (Proxies)**：策略组横向滑动、Grid 宫格与 List 列表一键切换、一键并发测速与延迟高低自动排序。
   - **📑 订阅管理 (Profiles)**：流量使用条形进度、到期倒计时预警徽标、单项/全量一键刷新动画。
   - **🔀 应用分流 (Apps & Rules)**：分流模式（绕过大陆 / 仅代理选定 / 绕过选定）、应用列表勾选与已选应用计数、活跃连接实时监控。
   - **⚙️ 系统设置 (Settings)**：TUN 模式、DNS 嗅探与防污染、开机自启、WebDAV 同步及实时终端日志 (Logcat)。
4. **极致的多维质感与无缝主题适配**：
   - **深色暗夜 (Dark Mode)**：深邃黑 `#0C0D11` 与卡片 `#16181F`，配合精细 0.5px 微透明描边与霓虹高亮。
   - **浅色明亮 (Light Mode)**：柔和护眼灰底 `#F2F4F8` 与纯白卡片，清晰自然的对比度。
   - **双视图容器**：支持真机模型外壳（灵动岛、前摄打孔、状态栏）与全屏平铺模式自由切换。
