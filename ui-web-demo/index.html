网络协议栈 (Network Stack)
选择 Android TUN 虚拟网卡底层运行的 TCP/IP 协议栈实现：
gVisor (推荐) 默认
Google 用户态网络栈，稳定兼容 Android 10-15，高并发与游戏防丢包首选。
System (系统原生栈)
利用 Android Linux 内核网络栈转发，CPU 开销稍低，个别设备可能存在 UDP 阻断。
Mixed (混合模式)
TCP 采用系统原生栈，UDP 走 gVisor 用户栈，兼顾吞吐量与稳定性。
