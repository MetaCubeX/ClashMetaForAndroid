# 需求

现行需求在 [docs/product/requirements/](../../docs/product/requirements/INDEX.md)。下面是拆分前的合订正文。

## PRD-001 隧道

使用者打开 VPN 后，流量按当前配置进入 mihomo。服务运行在独立于界面的进程中。关闭或重载不要求使用者重装应用。

## PRD-002 配置

使用者可以导入配置、在多份配置之间选择当前一份，并保留本地覆盖。导入入口接受 `clash://install-config` 与 `clashmeta://install-config`。

## PRD-003 访问控制

使用者按已安装应用选择谁进入隧道。列表顶部提供系统应用与国内应用两个集合。集合按当前安装计算。隐藏系统应用只影响行是否显示，不改变集合成员。点选集合时：未全选则选中全部当前成员，已全选则只取消这些成员，其他已选应用保持不变。空集合不可点。

离开这个列表时立刻保存并返回。隧道重载和 WebDAV 同步在返回之后进行，不挡住页面关闭。只有这份名单正在驱动已运行的隧道时才重载：没有生效分流策略时是全局名单，有生效策略时是那一份策略。

## PRD-004 分流策略

使用者可以保存多份命名的应用名单，并指定哪一份正在生效。编辑某一份策略时，保存的是那一份，不是全局名单。

## PRD-005 WebDAV

使用者可以把配置和分流策略与 WebDAV 目录同步。公共地址必须是 HTTPS。局域网地址可以是 HTTP。未填写密码时不会自动同步。拉取应用到本机。推送上传合并结果，不把远端名单写回本机已导入的配置。

## PRD-006 外部控制

其他应用可以通过导出的控制入口请求启动、停止或切换隧道。Manifest 里登记的动作使用 meta 包名下的 `START_CLASH`、`STOP_CLASH` 和 `TOGGLE_CLASH`。
