# 当前快照

**日期**：2026-10-25

**应用语言**：设置 → 应用 → 界面的第一项是语言。点整行选择，第一项是跟随系统，后面按 `locales_config.xml` 列出 English、日本語、한국어、Русский、Tiếng Việt、简体中文、繁體中文（香港）、繁體中文（台灣），名称用各语言自己的文字。默认不写偏好，跟随系统，包括 Android 13 的按应用语言。选中后写入 `ui` 的 `app_language` 并重建界面。页面标题在重建时按当前语言重新读取。`:background` 启动时套用同一项；已在运行时收到广播后，下一次取文案用新语言，已经显示的通知要等刷新。空值和无法识别的值按跟随系统。

**当前**：显示名是 ClashMetaX。用户可见屏幕的根视图是 Compose。首页在连接之下是规则、全局、直连三个按钮；隧道运行时显示上下行速率和当前节点。其余屏幕用同一套分组列表。决定见 [ADR-002](../decisions/002-compose-ios-home.md)，行为见 [界面](../../docs/systems/ui/INDEX.md)。已落地的规格见 [分组交互](../plans/compose-remaining-screens.md)、[界面视觉收口](../plans/ui-visual-consistency.md) 和 [四处时序修复](../plans/ui-timing-fixes.md)。

底部弹层不再跟系统窗口一起缩放。遮罩从透明淡到 40% 黑，弹层从底部滑入，收起时反过来，250ms 后才关闭。`:app:assembleMetaRelease` 已通过，并覆盖安装。配置页打开 Tag 的更多后点遮罩关闭，录屏里遮罩整屏变暗、弹层上下移动。没有点更新、编辑、删除或新建。当前配置仍是 vultr，隧道仍停止。

显示收口已覆盖安装。这次只读看过首页、设置、网络、覆写、Meta、分流策略、策略名单、日志、帮助、关于、配置和 WebDAV。没有改当前配置、模式、访问控制名单或 WebDAV 自动同步，也没有点更新、同步、重置或保存：

- 停止且没有配置时，首页主按钮是「选择配置」，打开配置列表
- 模式说明下始终有「仅本次会话有效」。模式仍只写当前会话
- 首页和分流策略页用「应用分流」。允许全部的策略不显示已选 0 个应用
- 从策略进入的名单标题是策略名称。从网络设置进入的标题是「全局应用名单」。已有生效策略时，网络里仍显示模式名和包列表说明，下面另有一句接管提示。名单上方显示已选数量。写入目标不变
- 设置每一行有说明。实时日志级别用翻译名。搜索清除读作「清除」。行尾短值按宽度计算，汉字算两个字母。WebDAV 短地址在行尾
- 会话提示比模式说明更浅
- 配置和文件的更多是图标，菜单标题是名字。已导入的订阅和外部配置在更多左边有更新图标，菜单里不再放更新。文件配置只有更多。配置行不显示箭头。普通订阅不重复写类型。有总量时用量后面带百分比。过期日期是红色，写在副标题里。有到期日时行上不写「几天前」
- 帮助页和安装包损坏页的网址在斜杠后可以换行
- 覆写和 Meta 的短值在行尾，长值在标题下。重置是红色。嗅探分组标题是「嗅探设置」，其中一行是「嗅探策略」
- 没有历史日志时不显示清空。提供者空列表是「这里是空的」。关于对话框有确认，只关闭
- 简体、繁体和香港的覆写字段不再回落成英文。自动同步说明是一整句

带导航栏的屏幕仍把滚动内容裁在标题下面。配置已用流量在没有总量时不带单独的斜杠。网络协议栈选项用中文。

手机上对过的显示：未选配置时主按钮是选择配置，模式下面有仅本次会话有效。设置五行都有说明。网络在生效策略下仍显示模式名和包列表说明，下面另有接管提示，VPN 说明是一行。覆写滚动后标题仍在。分流策略页标题是应用分流，允许全部不显示已选 0 个。从策略打开的名单标题是策略名，上方有已选数量。日志空列表是这里是空的。帮助网址在斜杠后换行。配置更多是图标，过期订阅在日期前写已过期，菜单取消完整留在弹层里。WebDAV 短值在行尾，滚到底后最后一个动作完整可见。

先前仍在：外部资源按目录打开，列出缺失目录会先建目录并更新该配置的修改时间。外部控制在没有已导入配置时不启动。见 [界面](../../docs/systems/ui/INDEX.md)、[文件提供者](../../service/docs/documents.md)、[PRD-006](../../docs/product/requirements/PRD-006.md)。网络里的生效策略名只在打开该页时读取。代理和提供者这次没看，因为隧道是停止的。
